# Python - Input/Output

Scripts covering file I/O and JSON serialization/deserialization in
Python: reading and writing text files, converting Python data
structures to and from JSON, saving/loading objects to and from
JSON files, and a Pascal's triangle warm-up exercise.

## Tasks

| File | Description |
| --- | --- |
| `0-read_file.py` | Reads a text file (UTF8) and prints it to stdout |
| `1-write_file.py` | Writes a string to a text file, returns chars written |
| `2-append_write.py` | Appends a string to a text file, returns chars added |
| `3-to_json_string.py` | Returns the JSON string representation of an object |
| `4-from_json_string.py` | Returns the Python object represented by a JSON string |
| `5-save_to_json_file.py` | Writes an object's JSON representation to a file |
| `6-load_from_json_file.py` | Creates an object from a JSON file |
| `7-add_item.py` | Adds CLI arguments to a list saved in `add_item.json` |
| `8-class_to_json.py` | Returns a JSON-serializable dict of a simple class instance |
| `9-student.py` | `Student` class with a `to_json` method |
| `10-student.py` | `Student` class with a filterable `to_json` method |
| `11-student.py` | `Student` class with `to_json` and `reload_from_json` |
| `12-pascal_triangle.py` | Returns a list of lists representing Pascal's triangle |

## Requirements

- Ubuntu 20.04 LTS, Python 3.8.5
- pycodestyle 2.7.*
- All files start with `#!/usr/bin/python3`, end with a new line, and
  are executable
