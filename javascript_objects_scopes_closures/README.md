# JavaScript - Objects, Scopes and Closures

Learning how objects work in JavaScript: classes, inheritance
(`extends` and `super`), prototypes, `this`, variable scope, and
closures. All scripts run with Node.js and follow the semistandard
style guide.

## Files

| File | Description |
| --- | --- |
| `0-rectangle.js` | Empty `Rectangle` class |
| `1-rectangle.js` | `Rectangle` with `width` and `height` |
| `2-rectangle.js` | `Rectangle` that rejects invalid sizes |
| `3-rectangle.js` | Adds a `print()` method |
| `4-rectangle.js` | Adds `rotate()` and `double()` methods |
| `5-square.js` | `Square` inheriting from `Rectangle` |
| `6-square.js` | Adds `charPrint(c)` to `Square` |
| `7-occurrences.js` | Counts occurrences of an element in a list |
| `8-esrever.js` | Reverses a list without `reverse` |
| `9-logme.js` | Logs items with a running counter (closure) |
| `10-converter.js` | Base converter (closure) |
