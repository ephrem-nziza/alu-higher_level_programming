The ``1-my_list`` module
========================

Using MyList
------------

>>> MyList = __import__('1-my_list').MyList

>>> my_list = MyList()
>>> my_list.append(1)
>>> my_list.append(4)
>>> my_list.append(2)
>>> my_list.append(3)
>>> my_list.append(5)
>>> print(my_list)
[1, 4, 2, 3, 5]
>>> my_list.print_sorted()
[1, 2, 3, 4, 5]
>>> print(my_list)
[1, 4, 2, 3, 5]

Not sorted append with a negative number
-----------------------------------------

>>> neg_list = MyList()
>>> neg_list.append(7)
>>> neg_list.append(-3)
>>> neg_list.append(0)
>>> neg_list.append(-10)
>>> print(neg_list)
[7, -3, 0, -10]
>>> neg_list.print_sorted()
[-10, -3, 0, 7]
>>> print(neg_list)
[7, -3, 0, -10]

Empty list
----------

>>> empty = MyList()
>>> empty.print_sorted()
[]

Single element
---------------

>>> one = MyList()
>>> one.append(42)
>>> one.print_sorted()
[42]
