# 0x07. Python - Everything is object

## Description
This project explores how Python handles objects under the hood: identity (`id`), type, mutability vs immutability, referencing vs assignment, aliasing, and how arguments are passed to functions.

## Answer files
Each numbered `.txt` file answers a specific question about Python's object model — comparing `==` (value equality) vs `is` (identity), tuples vs non-tuples, and memory address behavior after list/int operations.

## 19-copy_list.py
Returns a shallow copy of a list using slice notation `l[:]`.

## Learning objectives
- What an object is, and the difference between a class and an instance
- Mutable vs immutable types, and Python's built-in examples of each
- References, assignment, and aliasing
- How to check object identity (`is`, `id()`) vs value equality (`==`)
- How Python passes arguments to functions (by object reference, not by value or by pointer in the C/Java sense)
