# JavaScript - Warm up

Learning the fundamentals of JavaScript: variables (`let`/`const`),
data types, control flow, functions, loops, arrays, objects, and
Node.js module exports. All scripts run with Node.js and follow the
semistandard style guide.

## Files

| File | Description |
| --- | --- |
| `0-javascript_is_amazing.js` | Prints a constant string |
| `1-multi_languages.js` | Prints 3 languages, one per line |
| `2-arguments.js` | Handles script arguments (`process.argv`) |
| `3-value_argument.js` | Prints the first argument passed |
| `4-concat.js` | Concatenates two arguments into a sentence |
| `5-to_integer.js` | Converts an argument to an integer |
| `6-multi_languages_loop.js` | Prints languages using a loop and array |
| `7-multi_c.js` | Prints "C is fun" N times using a loop |
| `8-square.js` | Prints a square made of "X" characters |
| `9-add.js` | Adds two integers using a function |
| `10-factorial.js` | Computes factorial recursively |
| `11-second_biggest.js` | Finds the second biggest integer in arguments |
| `12-object.js` | Modifies an object's property |
| `13-add.js` | Exports an `add` function as a module |
