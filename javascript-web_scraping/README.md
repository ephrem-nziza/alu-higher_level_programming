# JavaScript - Web scraping

Working with files, HTTP requests and JSON in Node.js: reading and
writing files with the `fs` module, and calling APIs with the
`request` module. All scripts follow the semistandard style guide.

## Files

| File | Description |
| --- | --- |
| `0-readme.js` | Reads and prints a file |
| `1-writeme.js` | Writes a string to a file |
| `2-statuscode.js` | Prints the status code of a GET request |
| `3-starwars_title.js` | Prints a Star Wars movie title by ID |
| `4-starwars_count.js` | Counts movies featuring Wedge Antilles |
| `5-request_store.js` | Saves a web page body to a file |
| `6-completed_tasks.js` | Counts completed tasks per user |
